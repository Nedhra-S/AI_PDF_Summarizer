\# 🤖 AI PDF Summarizer



An AI-powered PDF summarizer built with Python, Streamlit, Ollama, and Qwen 2.5.



\## Features



\- 🔐 Login and logout

\- 📄 PDF upload

\- 📚 Full-document processing

\- 🤖 Local AI processing with Ollama

\- 📂 Document type detection

\- 📝 AI-generated summary

\- 🔑 Separate key points

\- ⬇️ Download summary

\- ⬇️ Download key points

\- ⚡ Progress indicator



\## Technologies Used



\- Python

\- Streamlit

\- PyPDF

\- Ollama

\- Qwen 2.5 3B



\## How It Works



PDF  

↓  

Text Extraction  

↓

↓  

Document Split into Sections  

↓  

Important Information Extraction  

↓  

AI Summary + Key Points
